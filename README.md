# generaticMed

## Frontend

`cd frontend`, copy `.env.example` to `.env`, then run `npm install` and `npm run dev`.

## Backend

`cd backend`, copy `.env.example` to `.env`, then run `npm install` and `npm run dev`.

The frontend runs on port 3000 and proxies `/api` and `/fhir` requests to the backend on port 3001. Run each command in a separate terminal.
